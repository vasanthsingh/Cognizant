Exercise 2.1 — Bootstrap folder structure (notes below)

Downloaded Bootstrap typically has: css/ (compiled CSS), js/ (bundled JS plugins), and icons/ (optional icon fonts).

  • css/ — main stylesheet and source maps.
  • js/ — bootstrap.bundle.min.js includes Popper and plugins (tooltips, modal, collapse).
  • icons/ — optional icon fonts or SVG sprite (not part of core Bootstrap).
